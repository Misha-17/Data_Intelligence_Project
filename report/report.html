Antimicrobial resistance prediction

1. Task and study sample

This study predicts a laboratory susceptibility result at the time a culture is ordered. The final dataset has 182,487 rows from 15,952 patients and 28,498 cultures. LightGBM, weighted was selected using validation data. Its test drug-macro AUROC was 0.707.

One row is one patient, culture event, organism and candidate antibiotic. Susceptible is 1. Resistant is 0. Only observed results are used. Untested drugs have no label. Current organism identity defines the row but is excluded from predictors because it is usually unknown when the culture is ordered.

The public ARMD files come from two affiliated hospitals and use an adult cohort [1]. The release is Dryad version 403223, dated 22 October 2025 [2]. The 14 supplied files match the publisher's checksums. A fixed hash selected about 25.0% of patients before data cleaning. This is a scaled sample, not the full source cohort.

The nine candidates are ampicillin, amoxicillin/clavulanate, cefazolin, cefepime, ceftriaxone, ciprofloxacin, gentamicin, piperacillin/tazobactam, trimethoprim/sulfamethoxazole. This panel was set before model fitting. The instructor list was not supplied. It is a provisional ARMD panel, not a verified STEWARD-AW panel.

Data preparation

2. Labels, joins and missing values

The pipeline scanned 2,241,050 cohort rows and selected 560,188 by patient. After key, date, candidate and culture checks, 188,489 target rows entered label review.

Matching S results or matching R results were collapsed. Label review rejected 5,031 keys: 4,484 with an unsupported or missing result, and 547 with conflicting S and R results. It collapsed 0 extra agreeing rows. Untested, intermediate and unknown results were not used as labels.

The pipeline removed 0 events with conflicting dates or culture descriptions. Repeated support values had to agree; conflicts became missing. Each support table had one row per intended join key. Joins had to preserve cohort row counts. Missing age was retained under ARMD's adult inclusion rule; explicit under-18 bands were excluded.

The model uses 15 predictors: candidate, culture type, age band, anonymous gender code, four ward flags and 7 numeric summaries. The extra summaries cover laboratory tests, vital signs and prior antibiotic or resistance records. The dictionary gives each field's source, timing rule and missing-value rule.

The source defines laboratory summaries over the prior 14 days and vital signs over the prior 48 hours [1a]. Separate result-release times are absent, so availability at order cannot be checked for each measurement. Values retain source units. Prior history uses only the positive, strictly earlier day differences defined in the feature contract. No linked history means unknown, not no history.

Missing categories receive their own code. Numeric gaps use medians learned from model-fitting patients, with separate flags for missing values. Scaling also uses only those patients. Model fitting and evaluation

3. Keep training and testing separate

A separate patient hash assigned about 60% to training, 20% to validation and 20% to testing (seed 42). All rows from a patient stay together. The audit found 0 patients shared across these sets. Patient codes, event codes, shifted dates, current organism and current susceptibility details are excluded from predictors.

Within training, 7,681 patients fit the models and 1,921 different patients fit sigmoid probability calibration [3]. Categories, medians, scaling and class weights use only the model-fitting subset. Validation and test data were not rebalanced.

Logistic regression and LightGBM [4] were each fitted with and without balanced class weights. Two baselines predict the training susceptible share, either overall or for each drug. Model settings were fixed in advance. Weighted fitting gives each class the same total training weight; it does not add synthetic rows.

Validation selected the learned model with the highest mean resistant average precision across drugs, using lower Brier score to break ties. Each model's threshold maximized validation balanced accuracy. These choices were frozen before test scoring. Calibration used only the held-out training subset, not validation or test labels.

Overall, 18.5% of labels are resistant; resistant is the smaller class. The table shows each drug's class balance. R means resistant and S means susceptible.

AUROC measures score ranking: 0.5 is chance and 1 is perfect. Drug-macro AUROC averages it across drugs with both classes. Macro AUPRC averages susceptible and resistant average precision within each drug, then across drugs. AUPRC here means average precision, not trapezoidal area. Balanced accuracy averages the two class recalls. Resistant precision measures how often a resistance alert is correct; resistant recall measures how much resistance is found. Lower Brier score means less probability error.

* Selected using validation data. All 9 test drugs have both classes. At its validation-set threshold of 0.812, LightGBM, weighted found 73.2% of resistant results; 37.7% of its resistance alerts were correct. Its mean resistant AUPRC across drugs was 0.381.

The selected model's drug-macro AUROC was 0.707 (95% interval 0.682 to 0.722). Its Brier score was 0.118 (95% interval 0.114 to 0.123). The intervals resample patients 200 times, keeping all rows for each sampled patient together. They measure uncertainty in this test sample with fitted models held fixed.

For the selected model, test Brier score was 0.1791 before calibration and 0.1182 after calibration. Brier score reflects both ranking and calibration, so this comparison alone does not prove better calibration [3].

Compared with unweighted logistic regression, the selected model's drug-macro AUROC difference was 0.009 (paired 95% interval 0.001 to 0.014). The same patient samples were used for both models. This estimates their difference in this test set, not in a new hospital.

Further checks are in advanced_analysis.pdf. At the original cutoff, all 4,637 ampicillin rows were flagged, including 2,361 false alerts. All 108 resistant piperacillin/tazobactam rows were missed. An overall recall score hides these drug differences.

On validation, adding prior history to the basic fields raised mean resistant AP from 0.250 to 0.375. Using all features scored 0.373. The paired interval showed no clear added gain from these lab and vital summaries. These follow-up comparisons used fixed model settings. They did not select a new model or change the original test results.

Independent dataset or hospital validation was not possible. The supplied ARMD files do not identify the two hospitals separately. Ward and culture groups cannot replace an outside-site test. Patient separation also does not test future years, since calendar dates are shifted.

Labels cover tested drugs with clear results. Testing choices may depend on the patient, organism and laboratory rules. Results may differ for untested drugs. Excluding intermediate or conflicting labels also changes the sample.

The current organism is unknown at culture order. Different organisms in one culture can have the same inputs but different outcomes. Exact feature release times and some units are also unavailable. These results do not measure treatment benefit.

The next checks are to confirm the instructor's drug list, obtain a hospital field or second dataset, and verify feature release times and units. The code can rerun the study when these inputs are available.
